Full pipeline

Every package in the repo runs in sequence: qc_research ingests and ranks targets, qc_model trains a potency predictor from scratch on the winner's chemistry, and the best-supported candidate gets scored across six categories. It selects and scores real measured chemistry — it does not invent molecules.
